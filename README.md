# Jarvis Clipper

Trova le clip più virali di un VOD Kick o di una registrazione, le taglia in verticale (cam sopra, gioco sotto) e le esporta per Premiere Pro.

**Download:** vai su *Releases* e scarica `JarvisClipperSetup.exe`.

Ogni push su `main` costruisce automaticamente l'installer Windows (GitHub Actions), lo collauda con un autotest e lo pubblica nelle Releases.
